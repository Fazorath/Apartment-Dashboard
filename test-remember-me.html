Test Instructions

How to test Remember Me functionality:

  1. Test with Remember Me: Click "Login with Remember Me" then refresh the page. The token should persist.
  2. Test without Remember Me: Click "Login without Remember Me" then refresh the page. The token should be cleared.
  3. Test browser restart: Close and reopen the browser. Only "Remember Me" tokens should persist.
  4. Test logout: Use the logout function to clear all tokens.
